All guides · എല്ലാ ഗൈഡുകളും

⚡ Speed & startup · വേഗതയും സ്റ്റാർട്ടപ്പും

  • Laptop / PC is very slow ലാപ്ടോപ്പ് / കമ്പ്യൂട്ടർ വളരെ സ്ലോ ആണ്
  • PC hangs or freezes PC ഹാങ് ആകുന്നു / ഫ്രീസ് ആകുന്നു
  • PC / laptop won't turn on (no power) PC / ലാപ്ടോപ്പ് ഓൺ ആകുന്നില്ല
  • Windows won't start (stuck on logo / automatic repair / restart loop) Windows start ആകുന്നില്ല (logo-യിൽ നിൽക്കുന്നു / automatic repair / restart loop)
  • Blue screen error (BSOD) നീല screen error (Blue Screen / BSOD)

🔋 Power, battery & heat · Power, battery, ചൂട്

  • Laptop overheating / loud fan ലാപ്ടോപ്പ് ചൂടാകുന്നു / fan ശബ്ദം കൂടുതൽ
  • Laptop battery draining fast ലാപ്ടോപ്പ് battery പെട്ടെന്ന് തീരുന്നു
  • Laptop not charging (“plugged in, not charging”) ലാപ്ടോപ്പ് ചാർജ് ആകുന്നില്ല (“plugged in, not charging”)

🪟 Windows & storage · Windows, storage

  • Windows Update stuck or failing Windows Update stuck ആകുന്നു / fail ആകുന്നു
  • C: drive full / low disk space C: drive നിറഞ്ഞു / disk space കുറവ്
  • Forgot Windows password or PIN Windows password / PIN മറന്നുപോയി
  • Wrong date/time on PC PC-യിൽ സമയം / തീയതി തെറ്റാണ്

📶 Internet & Wi-Fi · Internet, Wi-Fi

  • Wi-Fi connected but no internet Wi-Fi connect ആണ്, പക്ഷേ internet ഇല്ല
  • Wi-Fi not showing / can't find networks Wi-Fi കാണിക്കുന്നില്ല / networks കാണുന്നില്ല
  • Internet is slow Internet സ്ലോ ആണ്
  • LAN / Ethernet cable not working (“Unidentified network”) LAN / Ethernet cable വർക്ക് ചെയ്യുന്നില്ല (“Unidentified network”)
  • Website not opening / “This site can't be reached” Website തുറക്കുന്നില്ല / “This site can't be reached”

🖨️ Printer & scanner · Printer, scanner

  • Printer shows “Offline” Printer “Offline” എന്ന് കാണിക്കുന്നു
  • Printer not printing / jobs stuck in queue (Print Spooler) Printer print ചെയ്യുന്നില്ല / queue-ൽ കുടുങ്ങുന്നു (Print Spooler)
  • Printer paper jam Printer-ൽ പേപ്പർ കുടുങ്ങി (Paper jam)
  • Faded print, lines, streaks or blank pages Print മങ്ങുന്നു, വരകൾ, അല്ലെങ്കിൽ blank page വരുന്നു
  • Scanner not working Scanner വർക്ക് ചെയ്യുന്നില്ല

⌨️ Keyboard, mouse & USB · Keyboard, mouse, USB

  • Keyboard not working / wrong letters Keyboard വർക്ക് ചെയ്യുന്നില്ല / തെറ്റായ letters വരുന്നു
  • Touchpad not working Touchpad (mouse pad) വർക്ക് ചെയ്യുന്നില്ല
  • Mouse not working Mouse വർക്ക് ചെയ്യുന്നില്ല
  • USB / pen drive not detected USB / pen drive detect ആകുന്നില്ല
  • Bluetooth not working / can't pair Bluetooth വർക്ക് ചെയ്യുന്നില്ല / pair ആകുന്നില്ല
  • Webcam / camera not working (Teams, Zoom, Meet) Webcam / camera വർക്ക് ചെയ്യുന്നില്ല (Teams, Zoom, Meet)

🖥️ Display & sound · Display, sound

  • No sound from laptop / PC ലാപ്ടോപ്പ് / PC-യിൽ sound ഇല്ല
  • Microphone not working (others can't hear me) Mic വർക്ക് ചെയ്യുന്നില്ല (മറ്റുള്ളവർക്ക് എന്നെ കേൾക്കുന്നില്ല)
  • Projector / second monitor / TV not showing Projector / രണ്ടാം monitor / TV-യിൽ display വരുന്നില്ല
  • Screen black, flickering or showing lines Screen കറുപ്പ് / മിന്നുന്നു / വരകൾ കാണിക്കുന്നു

🛡️ Security & scams · സുരക്ഷ, തട്ടിപ്പുകൾ

  • Virus, pop-up ads or browser hijacked Virus / pop-up പരസ്യങ്ങൾ / browser hijack
  • Fake tech-support / remote-access (AnyDesk) scam വ്യാജ tech-support / AnyDesk തട്ടിപ്പ്
  • Email / social media account hacked Email / social media account hack ആയി

📊 Office, email & files · Office, email, files

  • Excel / Word not responding or crashing Excel / Word not responding / crash ആകുന്നു
  • Outlook / email not sending or receiving Outlook / email അയക്കുന്നില്ല / വരുന്നില്ല
  • Recover a deleted or lost file Delete ആയ / നഷ്ടപ്പെട്ട file തിരിച്ചെടുക്കാൻ

📱 Phone & WhatsApp · ഫോൺ, WhatsApp

  • Phone storage full ഫോൺ storage / memory നിറഞ്ഞു
  • WhatsApp chat backup / restore / new phone WhatsApp chat backup / restore / പുതിയ ഫോൺ
